# Impeccable Design Skill

Use this skill when designing, polishing, auditing, or structuring UI surfaces: landing pages, dashboards, app screens, components, and forms.

## Modes

1. **Persuade**: Landing pages, marketing, showcase surfaces. Earn attention with distinct point-of-view, confident scale, and real substance.
2. **Operate**: App UI, dashboards, data tables, admin portals, settings. Prioritize scannability, consistency, rapid interaction, quiet borders, and semantic color usage.
3. **Read**: Documentation, long-form guides, changelogs. Structure for legibility, hierarchy, and sustained reading.
4. **Experience**: Galleries, interactive showcases. The artifact leads; the UI recedes.

## Command Vocabulary

- **`polish`**: Final quality pass before shipping: spacing alignment, typography hierarchy, border crispness.
- **`audit`**: Technical checks for accessibility (WCAG), layout overflow, and performance bottlenecks.
- **`critique`**: Review UX hierarchy, emotional clarity, and user task flow.
- **`distill`**: Strip away extraneous elements, decorative bloat, and redundant panels.
- **`bolder`**: Amplify safe or bland designs with confident scale and contrast.
- **`quieter`**: Tone down aggressive, over-saturated, or visually noisy interfaces.
- **`harden`**: Ensure complete handling of edge cases, empty states, error states, and long strings.
- **`onboard`**: Refine first-run experiences and guidance.
- **`typeset`**: Enforce strict typographic ratio (hero scale, body measure, line height).
- **`layout`**: Correct grid rhythm, outer margins, and column distributions.

## Core Anti-Patterns

- Never wrap everything in cards, and never nest cards inside cards.
- Never use un-tinted pure black (`#000000`) or pure gray; always tint neutrals with brand undertones.
- Never use gray text on colored backgrounds.
- Never use bounce or elastic animation easing; prefer smooth cubic-bezier transitions (`ease-out`).
- Avoid default AI fonts (pure Arial/Inter defaults without custom weight/tracking calibration).
